# 🧪 GUI Automation Testing Tool

An automated testing framework for desktop GUI applications, built in **C#** to simplify and accelerate regression testing of WPF/WinForms applications.  
Designed for developers and QA engineers looking to improve testing accuracy and reduce manual effort.

---

## 🚀 Features

- ✅ Automates interaction with desktop UI elements (buttons, forms, menus, etc.)
- ✅ Supports assertions and validations on UI state and data
- ✅ Works seamlessly with legacy and modern desktop applications
- ✅ Designed to be readable, reusable, and scalable
- ✅ Logs test results and screenshots for failed cases

---

## 🔧 Built With

- [.NET Framework 4.8]
- [TestStack.White](https://github.com/TestStack/White) 
- [NUnit]
- C#
